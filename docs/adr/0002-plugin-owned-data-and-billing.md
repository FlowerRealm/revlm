# 插件数据与数据库生命周期

状态：accepted

核心负责核心 schema、请求记录、最终扣款和计费持久化；插件负责协议专属数据库、配置和业务表，以及迁移、卸载清理、协议原始数据解析和协议计费语义。插件根据协议 usage 得出协议计费结果，但不直接扣用户余额、不写核心请求记录。启动顺序固定为核心 schema、插件迁移、服务启动；安装和更新都在下一次启动时执行同一个幂等迁移入口，卸载则先执行插件清理入口，成功后才删除插件文件。

这保留了插件对协议专属数据库、协议数据模型和协议计费语义的所有权，同时明确最终扣款、ChannelGroup 倍率和核心请求持久化属于 Revlm 核心。核心不解析协议 token JSON，也不要求所有协议共享固定 token 字段。
