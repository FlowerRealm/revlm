# 使用受信任的原生插件并以文件系统作为安装真相

状态：accepted

Revlm 将用户安装插件视为完全信任的原生代码，不提供安全边界、插件依赖、多版本并存或回滚。插件以稳定 ID 唯一安装，版本号只保留为清单元数据；更新直接替换同一插件目录，启用状态由文件系统标记表达，所有变更都等外部机制触发冷启动后生效。这样保留了 C++/hpp 的直接扩展能力，同时避免安装状态表、版本选择器和热加载状态机。

## 考虑过的方案

- 沙箱、签名、能力声明：与“安装即完全信任”前提冲突。
- 多版本目录、回滚和 active 符号链接：制造重复状态，且产品明确不需要。
- Revlm 自行重启或热加载：Revlm 没有自重启能力，热加载还会制造 worker 状态不一致。
